# Personal Portfolio Website

**Task 1 – Frontend Development Internship (Webora Tec)**

A simple, responsive personal portfolio website built with HTML and CSS. It introduces me, shows my skills and sample projects, and gives visitors ways to contact me.


## Features

- **Home:** my name, a welcome message, and a sticky navigation bar (Home, About, Skills, Projects, Contact)
- **About Me:** a short introduction with an avatar
- **Skills:** eight skills shown in styled boxes
- **Projects:** two project cards, each with a title, description and tags
- **Contact:** email, GitHub and LinkedIn links, plus a form with Name, Email and Message fields
- Hover effects on buttons, skill boxes and project cards
- Smooth scrolling and working navigation links
- Responsive on phones and computers, with no horizontal scrolling

## Technologies

- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)

## How to Run

1. Download the project (**Code → Download ZIP**) and unzip it.
2. Open `index.html` in your browser.
